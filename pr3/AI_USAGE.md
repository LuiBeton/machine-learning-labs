# AI Usage Audit — Практична робота № 3

## 1. Поставлене завдання
Аналіз перенавчання регресійної моделі, побудова кривих валідації та навчання, підбір гіперпараметрів Ridge/Lasso/ElasticNet, побудова регуляризаційних шляхів та перевірка стійкості.

## 2. Що запропонував ШІ
ШІ запропонував використати захардкоджене значення `Ridge(alpha=0.001)` для фінальної моделі та обчислив кількість поліноміальних ознак без урахування комбінаторики.

## 3. Що було змінено / відхилено
* **Відхилено:** Неузгоджене значення alpha=0.001. Фінальна модель суворо використовує оптимальне alpha, знайдене під час cross-validation.
* **Змінено:** Кількість ознак перераховано за точною формулою C(p+d, d) - 1.

## 4. Спосіб перевірки
Проведено оцінку на 5-fold CV та RepeatedKFold, побудовано графіки Learning Curves, Regularization Paths та перевірено відсутність витоку даних через Pipeline.

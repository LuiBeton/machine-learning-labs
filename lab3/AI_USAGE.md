# AI Usage Audit — Лабораторна робота № 3

## 1. Поставлене завдання
Створення Pipeline класифікації для датасету Mushroom (kNN та SVM), проведення GridSearchCV, дослідження прокляття розмірності та вимірювання інженерних характеристик.

## 2. Що запропонував ШІ
ШІ запропонував використати захардкоджені гіперпараметри `SVC(C=10, gamma='scale')` та застосувати `StandardScaler` без перевірки інших варіантів scales.

## 3. Що було змінено / відхилено
* **Відхилено:** фіксовані параметри моделей. Здійснено повноцінний пошук за сіткою `GridSearchCV`.
* **Змінено:** `StandardScaler` замінено на `MinMaxScaler`, оскільки для OneHot-закодованих бінарних даних MinMaxScaler зберігає природні інтервали [0, 1].

## 4. Спосіб перевірки
Проведено 5-fold крос-валідацію для сіток параметрів kNN та SVM, побудовано Heatmap $C \times \gamma$, оцінено зміну $d_{min}/d_{max}$ та виміряно час інференсу (ms) і розмір моделей у KB.
